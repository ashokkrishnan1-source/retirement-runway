Financial Tools of Life · Tool 3

Prism

Turn a whole-market screener download into a short reading list. Every company is asked five separate questions. The short list is the few that pass them all.

Today's file

Download the whole-market screener from your data provider with every column you can get. CSV is fastest; Excel also works. You can drop the file anywhere on this page. It is read in this browser and never uploaded. Prism lists companies to research. It does not tell you what to buy.

Columns found in the file

Five questions

Each question looks at different facts, so a yes on all five is five separate reasons, not one reason counted five times. Press a question to stop requiring it.

Nine ways in

Named situations that are often worth a look. Pick one to see only those companies. It combines with the questions above.

Companies

Look up any stock

Wondering why a company isn't on the list? Type its symbol to see how it answered each question, or why it was set aside.

Your verdicts

Record a verdict on any row so you don't read the same company again tomorrow. Rejected companies drop off every list until you bring them back.

Set aside

Nothing is deleted. These companies are in the file but were not scored, or are blocked for now.

Settings

Starting points, not tested rules. Change one and every list updates.

The last file you loaded is kept in this browser, so the page reopens where you left off.
